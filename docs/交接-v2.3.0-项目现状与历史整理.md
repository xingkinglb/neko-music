## 二、这个项目是什么

在 B 站搜歌 / 粘贴 BV 号或链接 / 导入 UP 公开收藏夹，把视频里的**音频流**在线播出来。三个最关键的技术点：

1. **WBI 签名** —— B 站要求每个搜索请求带签名，`src/bilibili.js` 负责算。
2. **`bili://` 私有协议** —— `<audio>` 标签没法自定义请求头，于是自己造一个协议，由主进程代发带 `Referer` 的请求。
3. **只取音频不下载视频** —— B 站的 DASH 格式把音视频分开存，取纯音频只要几 MB。

数据（歌单 / 收藏 / 历史 / 设置 / Cookie / 背景）全在本机 `%APPDATA%\neko-music\`，**不进 Git**。

5. **每轮回复最后附闸门快照 D1–D12**，并在**发送前最后一步**加载 `@skill:delivery-no-pseudoblock`。

## 五、每轮收尾流程（硬要求，缺一不可）

1. **记录改动**：功能变更进 `CHANGELOG.md`（面向 Neo、说人话）；开发过程与踩坑进 `.workbuddy/memory/YYYY-MM-DD.md`（**追加，不要覆盖旧文件**）。
2. **同步版本号**：`package.json` 的 `version` 与 CHANGELOG 标题一致（`package-lock.json` 有两处，都要改）。
3. **本地提交**：`git add -A` + `git commit`，提交信息写清「改了什么 + 根因 + 验证结论」。
4. **推送 GitHub**：先直接 `git push origin main`；只有在真的连不上时才退回 `.verify/push_via_api.py`（备选是 Neo 双击 `同步到GitHub.bat`）。
5. **汇报时告诉 Neo**：本地领先 `origin/main` 几个提交（`git rev-list --count origin/main..HEAD`），这次有没有推送成功。
6. **发 tag + Release**（版本规则：新功能中间位 +1，纯修 bug 末位 +1）。
7. **用 `present_files` 交付**（安装包 + Release 链接），并附 D1–D12 快照。

**D1–D12 是什么**：需求覆盖 / 施工图先写后做 / 实测非断言 / 回归全套 / CHANGELOG / 版本号 / README / 技术说明 / 交接文档 / 工作日志 / 提交推送 / tag+Release 这 12 道闸门，每轮逐条自检、未命中的要写原因。

## 六、技术踩坑清单（最容易重犯的）

完整版在 `docs/新会话交接提示词.md` 的「关键技术约定」一节（约 40 条）。这里只列**代价最大的**：

### 预览不能当验收（v2.2.1 最痛的一条）
`make-icons.js` 里画图函数形参写成 `(size, x, y)`，而调用处只传 `paint(x, y)` —— "尺寸"那一格被 x 坐标占了，写盘的 16 个图标全变成**纯色块**或**全透明**。但**接触表预览图是对的**，因为它走的是另一条写对了的代码路径。**两套代码 → 检查白做。**
**规矩：凡是"只在最后一步才写盘"的产物，都要把写盘的东西读回来验一遍。**（`check-icons.js` 就是干这个的：解码 PNG 数像素）

### 读档补洞绝不能写成白名单重建（v2.2.0 修的真 bug，v2.1.0 埋下）
`const s = { theme, volume, bg, glass, autoLyric }` 这种"只列认识的字段"会让**所有新加的设置项存得进、读不出**（症状：改了设置下次打开又变回去）。正确写法是 `const s = Object.assign({}, old)` —— **从存档里已有的出发，只补不删**。已抽成 `src/store-migrate.js`，`verify.js` 有两条哨兵守着（不许出现 `const s = {`、必须有 `Object.assign({}, old)`）。

### `setResizable(false)` 会把 min/max 一起钉死（v2.1.0）
这就是"不可缩放"的实现方式。所以退出 mini 还原尺寸时 `setResizable(true)` 必须放最前面，否则后面 `setMinimumSize` / `setMaximumSize` 全被无视；而且顺序要求"先放大 max、再调 min"（反了会出现瞬时 `min > max`，那一句被丢掉）。

### 捕获阶段监听的两个真实用途（v2.3.0）
- 录制快捷键时，按键要先于各面板自己的 Esc 监听被截住（`addEventListener(..., true)`）；
- "点框外取消录制"也必须在捕获阶段判断 —— 冒泡阶段时 target 已被 `innerHTML` 重建摘除，`closest('.key-list')` 断链，会误判成"点在外面"从而秒取消录制。**这是 test-keys.js 第一次实跑抓出来的。**

### CSS 两条静默失效
- `rgba(var(--x) / a)` 是**非法写法**，整条被丢弃且**不报错**。正确：`rgb(var(--x) / a)`。（v2.0.0 波及 40 处）
- 替换元素（`<video>` / `<img>`）光写 `position:absolute; inset:0` **不会撑满**，浏览器优先用固有尺寸。必须显式 `width:100%; height:100%` + `object-fit:cover`。（v1.9.0"窗口缩放只剩左上角"的根因）

### `backdrop-filter` / `filter` 的代价
模糊**正在播放的视频** = 每帧重新采样 + 重模糊。真省显卡的写法是 `backdrop-filter: none`（**不是 `blur(0px)`**）。默认档用 `buildGlassImage()` 预烘焙一张糊好的壁纸图当面板背景，所以**任何"作用在底图上的效果"（如压暗）都必须同时加进四块面板**，否则出现"只有内容区变了、面板没变"。

### 其他高频
- **`window.prompt` / `confirm` 在 Electron 里没实现**（返回 null，静默失效）→ 用项目自带的 `#promptMask` 模态框。
- **IPC 信封**：主进程 `handle()` 统一返回 `{ok, data}`，渲染层必须走 `api('xxx')` 解包。
- **`setThumbarButtons` 会静默失败**（返回 false 不报错），且必须在 `show()` **之后**调；只吃 `nativeImage` 不认 SVG；**一个图标空 → 整组按钮不显示**。
- **`setUserTasks` 不支持子菜单** → 层级菜单必须挂托盘。
- **`before-quit` 设"正在退出"标记**比手动 forceQuit 覆盖更全（托盘退出 / Ctrl+Q / 系统关机 / 任务管理器全走它）。**但 Neko 和参考项目 biu 的关键差别**：biu 关窗前不存盘，所以它 `if (quitting) return;` 直接放行；**Neko 必须仍走存盘握手**。规则："`before-quit` 标记跳过**询问**，不跳过**存盘**"。
- **离屏软件光栅"不重绘"**：滚动容器"改可见性"走合成器隐藏优化，DOM 计算样式明明是 hidden，画面上照旧。对策：**藏子元素**（不是藏容器）+ 另开新窗口拍照 + 截图前给子元素加/撤一次行内 `visibility` 逼重光栅化。看图工具有缓存，最终结论一律用 `capturePage().getBitmap()` dump 裸位图**直接数像素**。
- **`bg://` 资源失败会被缓存**：文件必须在 `loadFile()` 之前就位，否则首次 404 被缓存，之后设同一个 URL 也不重试。
- **`.ico` 是多分辨率容器**（16 / 32 / 48 / 256 四档，Vista 后允许内嵌 PNG）；**Windows 安装包（NSIS）要求 exe 图标至少含 256×256**。
- 手搓图形时**线条要对齐像素中心**（5.5 而不是 5），否则 1.6 宽的线骑在像素边界上，每像素最多覆盖 3/4，整枚图标比别的最淡一档。

## 十一、环境注意事项

- **跑 electron 测试必须 `env -u ELECTRON_RUN_AS_NODE`**：shell 里可能带着 `ELECTRON_RUN_AS_NODE=1`，不换掉的话 electron 会被当普通 node 跑（`app` 是 `undefined`）。本沙箱还要加 `--no-sandbox --disable-gpu-sandbox`（这是**测试环境**开关，**没进** `src/main.js`）。
- **electron 跑完不会自己退** → 用 `timeout N` 包一层，以 `*-report.txt` 的"退出码 N"为权威，跑完记得 `taskkill //PID <pid> //F` 清残留进程（不清会占着内存，还可能把后续 shell 卡死）。
- **离屏窗口不产生帧**：带 `transition` 的属性会"卡在切换前的旧值"上，取样前先注入 `* { transition: none !important }` 并强制一次重排。
- **两个 memory 目录别搞混**：`.workbuddy/memory/` 是**面向 Neo 的工作日志**（大文件、每轮追加、交接文档引用这个）；`.workbuddy-ai/memory/` 是系统记忆目录（已 gitignore，不提交）。
- 已知遗留：`test-collect.js` 后台重跑有时报 failed，其实是 electron 进程不退出导致的超时，**不是测试失败** —— `timeout N` 前台跑即可。
- `.gitattributes` 已规范换行（源码 LF，`.bat`/`.vbs` CRLF），别让 CRLF 制造假 diff。
- `docs/` 下有 11 份施工图（`改造计划-*.md`），每轮的历史决策和取舍都在里面，改相关功能前值得先翻。
