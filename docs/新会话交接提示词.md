## 关键技术约定（踩过坑的，别重犯）

- **IPC 信封**：主进程 `handle()` 统一返回 `{ok, data}`，渲染层必须走 `api('xxx')` 解包；直接调 `window.neko.*` 会拿到外壳 —— 这曾经导致"设置关掉就重置"的 bug，找了两轮。
- **`window.prompt` / `confirm` 在 Electron 里没实现**（返回 null，静默失效）。项目自带 `#promptMask` 模态框，用 `askName/askConfirm/pickPlaylistFor`。
- **CSS 陷阱**：`box-sizing:border-box` + `inset:0` + 百分比 padding 会让 `clientHeight` 膨胀（曾导致歌词浮层恒偏 191px）。要撑高度用伪元素 spacer。
- **Electron 离屏测试**：跑测试必须 `env -u ELECTRON_RUN_AS_NODE ./node_modules/.bin/electron xxx.js`（否则会当 Node 跑）；用 `offscreen:true` + `webContents.sendInputEvent` 合成鼠标事件 + `capturePage` 截图；electron 跑完不退出，命令前加 `timeout N` 收尾。
- **B 站接口**：搜索接口不返回分P数，用启发式猜（时长 ≥30min + 标题关键词）；点开才 `getVideoInfo`。UP 主页走 wbi 签名的 `space/wbi/arc/search`，**对未登录/风控敏感**，沙箱里大概率失败 —— 这类只能靠我本机验证，你要做优雅失败提示（引导去 ⚙ 设置填 Cookie）。
- **存档**：在 `%APPDATA%\neko-music\`，**不进 Git**；新增字段一律给缺省值 = 旧行为，**旧存档零迁移**。已扩过的字段：`settings.playMode`、`collectOff`、`collectParts`、`settings.bg`（v1.8.0 扩成 `{file, kind, dim, blur, video:{muted,loop,speed}}`，v1.9.0 再加 `perfLite` / `pauseOnBlur`，缺省 = `true`）。
- **替换元素（replaced element）的坑**：`<video>` / `<img>` 这类元素，光写 `position:absolute; inset:0` **不会撑满** —— 浏览器优先用它的**固有尺寸**，`right`/`bottom` 被忽略。必须显式 `width:100%; height:100%`，再配 `object-fit:cover` 才等比铺满。v1.9.0 的"窗口缩小只剩左上角"就是这个根因。
- **`backdrop-filter` / `filter` 的代价**：模糊**正在播放的视频**=每帧重新采样+重模糊。真省显卡的写法是 `backdrop-filter: none`（**不是 `blur(0px)`** —— 那仍会把背景拷进贴图）。静态图模糊一次就缓存，可以放心留。
- **`bg://` 资源失败会被缓存**：文件**必须在 `loadFile()` 之前**就位，否则首次 404 会被缓存，之后设同一个 URL 也不会重试（曾导致演示截图全黑，排查手法是 `capturePage().getBitmap()` 逐像素采样）。
- **测试里音频 `src` 桩不能给空串**：Chromium 会 `new URL('')` 抛 `Invalid URL`，污染报告；给个合法 URL（如 `https://example.invalid/a.m4s`）即可。
- **换行**：`.gitattributes` 已规范（源码 LF，`.bat/.vbs` CRLF）。别让 CRLF 制造假 diff。
