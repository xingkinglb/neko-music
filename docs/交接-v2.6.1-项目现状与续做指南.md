### 每一版的关键点

**v2.4.0** —— Neo 报的三条真机问题：
① mini 模式要像桌面歌词一样**置顶在所有窗口之上** → 用 Electron 最高的 `screen-saver` 档；
② 歌曲名过长时 mini 的图标被挤出窗口 → 根因是 **grid 项默认 `min-width:auto`**，不肯让位；
③ 合集展开后每行那个「加入队列」按钮多余（点播放本来就会入队），还把搜索框挤成只能显示一个字 → 直接删掉。

**v2.5.0** —— 「加载更多」这个模型本身缺信息：它只知道"再来 30 条"，没有"总数 / 我在第几页"的概念，所以画不出页码条。必须**先从 B 站拿到总投稿数**（`data.page.count`）才有"页"的概念 —— 这个数一直在返回里，只是以前只拿来算了个 `hasMore`、没往外传。

**v2.6.0** —— 侧栏「我的歌单」旁新增 ⬇ 按钮。Neo 特别要求：**选择必须能跨收藏夹累积**（在 A 里挑 3 个 → 回列表 → 进 B 再挑 2 个 → 最后一起落成**一个**歌单）。做法上最关键的三个决定：
- 选择集用 **`Map`（键 = 视频号）**而不是数组 —— "同一个视频只算一次"就成了**结构上保证**，不是靠额外判重；

- 挑歌行是**改列数**而不是多插一列（序号列拿掉、复选框顶上去，右侧操作列 `display:none`）。

## 三、★ 我是具体怎么实现项目的（方法论）

这一节是交接文档里**最该看的部分** —— 项目本身能跑，靠的是这套流程，不是靠某次灵光一现。

### 3.1 完整一轮的标准流程（10 步）

```
1. 勘察到行号级     读代码 + 跑脚本拿真实数据，不许凭猜
2. 写施工图         docs/改造计划-vX.Y.Z-*.md，逐条对账到代码行号
3. 等 Neo 批准      Neo 说「按你的建议做吧」才动手（小修小补可以不等）
4. 实施             按施工图改，改完自己再对一遍账
5. 静态自检         .verify/verify.js（新增/改动的点必须加断言）
6. 离屏实测         .verify/test-roundNN.js（真跑界面代码，不是文本断言）
7. 判别力实测       git stash push -- src/ 回退代码，确认新测试**会失败**
8. 回归             把老的测试套件全跑一遍
9. 出图 + 改文档     截图（假数据！）+ CHANGELOG / README / 技术说明 / 版本号
10. 发布           提交 → 推送 → tag → Release（含安装包）
```

### 3.2 每一轮都遵守的硬规矩

- **改完必须实测**，不许只写文字断言说"应该没问题"。
- **测试必须有判别力**：新写的测试要在**改之前的代码上真的失败**。这轮每次都做了 —— `git stash push -- src/` 回退源码再跑，v2.6.0 那次报 **47 处失败**，v2.6.1 那次报 **11 处失败**。测不出失败的测试等于没写。
- **反向断言**：凡是被删掉/换掉的错误写法，都要加一条断言防止它复活（例："不许退回 `list-all`"、"不许再无条件写行内 `background-image`"、"清空选择的地方必须正好 2 处"）。
- **收尾流程缺一不可**：记录改动（CHANGELOG + 工作日志）→ 同步版本号 → 提交 → 推送 GitHub → tag + Release。
- **每轮汇报要告诉 Neo**：本地领先 `origin/main` 几个提交（现在是 `0 0`），以及这次推送成功没有。

### 3.3 怎么定位根因（勘察方法）

**最重要的一条：先打印真实数据，别猜。**

v2.6.1 的封面 bug 就是这么查出来的 —— 界面代码看着没问题，那就只有两个可能：数据里没封面 / 图片加载被拦。于是：

1. 用 Neo 本机存的 Cookie（在 `%APPDATA%\neko-music\cookie.txt`）直接打接口，**把返回原样打出来** → 发现 `list-all` 接口根本没有 `cover` 字段；
2. 顺手把"图片被拦"这个假设也排掉：拿封面地址直接请求（带 / 不带 Referer）都是 `200 image/jpeg` → 不是防盗链也不是 CSP。

**两个假设都验过，结论才可靠。** 反过来，如果只看了代码就猜是 CSS 问题，改一天也改不出来。

> 提示：`src/bilibili.js` **只依赖 `https` 和 `crypto`**，可以直接 `node -e "require('./src/bilibili.js')..."` 跑真代码，不用起 Electron。

### 3.4 施工图怎么写

`docs/改造计划-vX.Y.Z-*.md` 的固定写法：

- 顶部写**状态**（待批准 / ✅ 已实施）、来源（谁提的、哪天）、版本规则（为什么是这个版本号）、依赖；
- 正文**逐条对账到代码行号**：「`src/ui/app.js:1234` 现在是这样 → 要改成那样」；
- 每条都带**验证判据**（怎么算做对了）；
- 末尾写「实施结果 + 与计划的差异」。

### 3.5 测试怎么写

- **离屏真跑界面代码**，不是文本断言。用 Electron 建 `offscreen:true` 的窗口，加载真的 `src/ui/index.html` + 真的 `preload.js`，用 `executeJavaScript` 读 DOM、`element.click()` 点。
- **桩只桩接口**（`ipcMain.handle('bili:xxx', ...)` 返回假数据），界面代码全用真的。
- **写桩前先问一句"这条路径上会不会漏掉什么"**。
- 想要验证"打了哪个接口"这种事：**直接打桩 `https.request`**，把请求 URL 记下来再断言（`test-round16.js` 第 1 组就是这么做的）。
- 报告写到 `.verify/<名字>-report.txt`（**不是 stdout**），结尾写"退出码 0/N"。

### 3.6 验证分三层

| 层 | 工具 | 管什么 |
|---|---|---|
| 静态自检 | `.verify/verify.js`（55 大类） | 引用了不存在的 id / CSS 变量没定义 / CSP 没放行 / **反向断言防代码复活**；第 55 类守歌词合并三闸门与 fail-closed |
| 离屏实测 | `.verify/test-roundNN.js` | 真跑界面，量具体数字（几行、几页、已选几个） |
| 回归 | 老套件全跑 | 确认没弄坏别的功能 |

出图后**要肉眼看一下**（`Read` 工具读 PNG），不自证。

### 3.7 出图的隐私红线

`.verify/shot-import.js` 出 `docs/images/import-*.png`：**全部用假数据**（测试喵 / 深夜爵士 / 爵士 1…），封面是内联 SVG 纯色块。**绝不能拿 Neo 真实的昵称、收藏夹名、视频标题出图。**

## 五、本次对话踩到的坑（最容易重犯，按痛感排序）

### #1 ★ Edit 的锚点跨过一个完整段落 → 整段被吞掉（真实数据丢失）

改 `CHANGELOG.md` 时，`old_string` 从 v2.4.0 的表格行一直跨到 `## v2.3.0`，**把中间的整个 `## v2.5.0` 段落（72 行）一起替换掉了**。

**教训**：改长 Markdown 时，**锚点绝不要跨过一个完整的 `##` 段落**。
**自检办法**：`git diff --numstat` 和 `git diff --ignore-all-space --numstat` **两个一起看** —— 两者相差很大 = 混进了纯排版噪声或意外改动。**最终修法是整份 `git checkout HEAD --` 还原，再只把新段落插回去**（diff 变成干净的 +78/−0）。

### #2 ★★ `$?` 取的是管道最后一个命令的退出码

`timeout 85 electron xxx.js | tail -6` 之后的 `$?` 是 **`tail`** 的退出码（恒为 0），**不是测试的退出码**。看着全绿，其实什么都没验到。

**正确写法**：重定向到文件再取：
```bash
timeout 85 env -u ELECTRON_RUN_AS_NODE ./node_modules/.bin/electron --no-sandbox --disable-gpu-sandbox .verify/xxx.js > /dev/null 2>&1
code=$?      # ← 这才是测试的退出码
```

### #3 ★★ 测试的输出根本不在 stdout

`test-round*.js` 的 `say()` 是 `fs.appendFileSync` 写到 **`.verify/<名字>-report.txt`**。stdout 里只有 libpng 警告。

**结论一律看报告文件**：`tail -3 .verify/xxx-report.txt`（结尾会写"退出码 0"）+ `grep -c FAIL`。
测试脚本用 `finish(fail === 0 ? 0 : 1)` 退出，所以**退出码是权威**；但即便 `timeout` 把它掐了（退出码 124），**报告早已写完**，照样能读。

### #4 Bash 工具默认超时 120 秒

把 `timeout` 设成 ≥120s（试过 120 / 150）会让**整个命令被工具 SIGTERM**，表现为"退出码 1 + 无输出"，看起来像测试崩了。
**前台跑把 `timeout` 控制在 ≤85s**；要跑更久就 **放后台**（`run_in_background`）。

### #5 Markdown 表格：追加到行尾 `|` 之后 = 多出的单元格被丢弃

我往表格行末尾追加内容时，追加到了 `|` **之后**（变成 `| A | B | C`）。GFM 里**多出来的单元格会被直接丢弃** —— 写了但**不显示**。
**修法**：把误插的 `|` 拿掉，内容放进最后一个单元格，再补回行尾 `|`。**改完要校验每张表每行的管道符数量跟表头一致。**

### #6 块注释里写 `**/*` 会提前把注释闭合

`/* ... 走默认 **/* ... */` —— `**/*` 里的 **`*/`** 提前终止了块注释，后面全被当成代码，直接 SyntaxError。
**写 `**/*` 这类含 `*/` 的文本时，别放进块注释**（改用行注释或改写措辞）。

### #7 bash 里 `node -e "..."` 的反引号会被当成命令替换

含反引号（Markdown 代码标记）的脚本别写进 `node -e "..."`，会被 bash 解析成命令替换（报 `command not found`，甚至语法错）。
**改用 Write 工具写成 `.tmp/xxx.js` 再 `node .tmp/xxx.js`。**

### #8 只加 class 不够：行内样式会盖掉 CSS

给 `.thumb` 加 `.no-cover` 类想显示占位，**没用** —— 行内 `background-image` 优先级高于样式表，那条空的 `url('')` 会把 CSS 占位**盖掉**。
**必须连行内都不写**：`${f.cover ? ' style="background-image:url(...)"' : ''}`。

### #9 B 站两个"收藏夹列表"接口字段不一样（本次 bug 的真凶）

| 接口 | 一次拿几个 | 有 `cover` |
|---|---|---|
| `/x/v3/fav/folder/created/list-all` | 全部 | ❌ **根本没有这个字段** |
| `/x/v3/fav/folder/created/list?pn=&ps=` | 最多 100 | ✅ 有（还带 `attr_desc`/`intro`/`view_count`/`cover_type`） |

实测同一账号：**0/69 → 59/69**。两个接口的 `attr` **逐条完全一致**（所以「私密」判断不受影响）。
**换数据源前，凡是"界面拿它做判断"的字段都要先对齐一遍。**

## 七、环境注意事项（跑测试的正确姿势）

```bash
# 单跑一个（前台，timeout 控制在 85 以内）
cd /c/Users/Dico/WorkBuddy/Music
taskkill //F //IM electron.exe >/dev/null 2>&1
timeout 85 env -u ELECTRON_RUN_AS_NODE ./node_modules/.bin/electron \
  --no-sandbox --disable-gpu-sandbox .verify/test-round16.js >/dev/null 2>&1
taskkill //F //IM electron.exe >/dev/null 2>&1
tail -3 .verify/test-round16-report.txt      # ← 看结论
```

- **必须 `env -u ELECTRON_RUN_AS_NODE`**，否则 electron 被当普通 node 跑（`app` 是 undefined）。
- **必须加 `--no-sandbox --disable-gpu-sandbox`**（沙箱里渲染进程起不来）。
- **Electron 跑完不会自己退出**，用 `timeout` 包一层；跑完 `taskkill` 清残留进程（不清会卡住 shell）。
- **结论以 `*-report.txt` 为准**，不以 stdout 为准。
- 跑整套（7 个测试）约 20 分钟，**放后台跑**。
- `node -e` 里别写反引号（见坑 #7）；`child_process.execSync` 调 git/gh 会 **EBUSY**，改成重定向到文件再读。
