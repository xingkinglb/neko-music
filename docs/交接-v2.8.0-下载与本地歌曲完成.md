### 2.3 两个新 bug 修复（本轮）

**问题 A：文件夹里直接删文件后，绿勾还在、再点不肯重下**（已修）

- 根因：`rebuildDlKeys()` 是**纯字符串并集**，从不查磁盘 → 外部删文件留下幽灵条目。
- 修法（`src/ui/app.js`）：`sweepMissingLocal(force)` 批量体检（启动时 + 进相关视图；60 秒节流 + 单飞闸门 + 空库跳过；
  **查不到 = 当活**，避免误删）；`localFileAlive(entry)`；`revealOrRedownload(track, task)` ——
  点绿勾时当场 `stat`，文件在 → 开文件夹，不在 → 删记录 + 清滞留 `done` 任务 + 允许重下。
- ★ 附带发现第二个真 bug：行内下载按钮判据原为 `task && task.status === 'done'`，`dlTasks=[]` 时漏判 →
  必须改成 **`isDownloaded(track)`**。播放条按钮同理。
- 探针：`.verify/probe-ghost-cb.js`。

**问题 B：播放一卡一卡 → 彻底卡死，拖条/重播都在同一位置**（已修）

- 根因：音频地址带 `deadline` 签名，拿到后**一直用到结束从不刷新** → 中途过期 → Range 被拒 → 缓冲耗尽 stalled；
  老代码**只监听 8 个 audio 事件、没有 `stalled` / `waiting`** → 零自愈；拖条/重播用**同一个死地址** → 同一位置卡死。
- 修法（`src/ui/app.js`）：`realUrlOf` / `srcDeadlineAt`（校验合理 Unix 秒区间）、`refreshAudioUrl`（**换 src 前先记 `currentTime`**，
  加载好再接回）、`armDeadlineTimer`（提前 60 秒刷新）、`healOnStall`（监听 `stalled`/`waiting`，**8 秒冷却**，暂停时不动）。
- 探针：`.verify/probe-stall.js`（确认没监听 stalled、deadline 可解析）、`.verify/probe-heal.js`（自愈实测全 PASS）。

- **Electron 测试跑完不会退出 → `timeout` 返回 124 是「预期」**，不是失败。
- Bash 工具默认 120s 会 SIGTERM 掉它 → **Electron 脚本一律 `run_in_background: true`**，读 `*-report.txt`。
- **`ELECTRON_RUN_AS_NODE`**：shell 里若带 `=1`，必须 `env -u ELECTRON_RUN_AS_NODE`（**空 `export` 不算 unset**，会让脚本以 exit=9 挂掉）。
