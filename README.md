# 🎧 Neko Music — 用 B 站当曲库的桌面音乐播放器

一个能**直接把 B 站视频里的音频在线播放**的桌面播放器。

支持：粘贴链接播放 · 关键词搜索 · 自动识别并展开合集 · 我的收藏 · 自建歌单 · 播放历史 · 导入 B 站收藏夹。

> 这份文档是写给你的教程。从上往下照做，半小时内就能跑起来。

---

## 一、怎么把它跑起来（3 步）

### 第 1 步：确认电脑有 Node.js

打开 PowerShell（按 `Win + R`，输入 `powershell` 回车），输入：

```powershell
node -v
```

如果显示 `v18.x` 或更高的版本号，就 OK。如果提示"不是内部或外部命令"，去 <https://nodejs.org> 下载 LTS 版安装，一路下一步即可。

### 第 2 步：双击启动

**双击 `启动播放器.vbs`**，软件窗口就出来了 🎉 干净利落，不会多出任何黑窗口。

> 💡 依赖（Electron）已经装好了，你**不需要**再运行 `npm install`。
>
> （如果你是**从 GitHub 克隆**下来的，那要先跑一次 `npm install`，把依赖装到本地。
> `node_modules` 体积有好几百 MB，所以没有放进仓库。）
>
> **为什么启动文件是 `.vbs` 而不是 `.bat`？**（这个坑很值得知道）
>
> `.bat` 一运行，Windows 就会开一个黑色的命令行窗口。而 `electron.exe` 是"图形程序"，
> 它会**继承**这个窗口 —— 等 bat 自己退出后，那个黑窗口还被 electron 拽着不放，
> 于是就成了一个关不掉的日志窗口，还不停往里刷消息。
>
> `.vbs` 由 `wscript` 执行，`wscript` **天生没有控制台**，它启动的程序自然干干净净。
> 原理就一句：**让"没有控制台的东西"去启动它。**
>
> **为什么不用 `npm start`？**
> 因为 `npm`/`npx` 依赖系统 PATH 里能找到 Node.js，不同电脑配置不一样，很容易失败。
> 而启动器直接调用 `node_modules\electron\dist\electron.exe` ——
> **Electron 自带运行时**，是个独立程序，跟你装没装 Node.js 完全无关。

### 出问题时：双击 `调试启动.bat`

它会**故意**保留黑窗口，把运行日志全部显示出来（包括网页里的报错信息）。
软件打不开、播放没声音的时候用它，把黑窗口里的内容截图发我就行。平时不需要。

## 二、怎么用

### ① 搜歌
顶部左边的搜索框输入歌名 / UP 主 / 关键词，回车。

### ② 粘贴链接播放
顶部右边的框，粘贴 B 站链接（`https://www.bilibili.com/video/BV...`）、短链（`b23.tv/xxx`）或纯 BV 号，点「解析」。

**如果这个视频属于某个合集，会自动把整个合集展开成播放列表** —— 这是本播放器最实用的功能，一键听完整张专辑。

### ③ 导入收藏夹
把 UP 主主页链接（`https://space.bilibili.com/数字`）粘到右边的框里，会列出他所有公开收藏夹，点进去就能整包听。

### ④ 歌单与收藏
- 某首歌右边的「收藏」→ 加入「我喜欢」
- 「＋歌单」→ 加入自建歌单（多个歌单会弹窗让你选序号）
- 左边栏「＋」→ 新建歌单
- 所有数据存在本地，关掉再开还在

### ⑤ 外观与体验自定义

点左下角 **⚙ 设置** 打开统一设置面板，分两个标签页：

- **外观**
  - **主题色**：樱粉 / 星夜紫 / 薄荷绿 / 落日橙 / 晴空蓝，五选一，立即生效
  - **背景图片**：点「选择图片」挑一张**本地图片**当壁纸（图片会复制进应用目录，删掉原图也不会裂图）；「清除背景」恢复默认深色
  - 还有四根滑杆：**压暗 / 模糊 / 毛玻璃强度 / 玻璃透明度**，按自己喜好调。侧边栏、顶栏、播放条都会变成磨砂半透明，透出后面的壁纸
  - 歌词相关的开关都搬到了旁边的「歌词」标签页，见下一节
  - 这些设置会**自动记住**，下次打开还是你调的样子
- **B 站**：填 SESSDATA（见第三节）

### ⑥ 歌词（两种看法，各管一个入口）

**一、桌面歌词 —— 浮在所有软件上面**

点播放条上的 **词** 按钮（或按 `Ctrl + L`），屏幕下方会挂出一个悬浮歌词窗。
它**浮在所有软件最上面**：你可以把播放器最小化、开着浏览器或文档，歌词照样跟着走。再点一次「词」就关掉。

- **取字幕需要先填 Cookie**（填法见第三节）。没填的话点了会提示你去填 —— 这是正常的，不是坏了。
  - 填的时候，浏览器开发者工具里复制 **Cookie Value** 那一列的内容即可，**不用**自己加 `SESSDATA=` 前缀。
- 悬浮窗怎么用：
  - **默认没有底板也没有边框** —— 屏幕上只有歌词文字，不会有一块黑方块贴在桌面上。
    （想要个板子垫着，可以在设置 →「歌词」页把「歌词底板」改成「半透明底板」。）
  - **拖动**：按住挪到屏幕任意位置，位置会记住，下次打开还在原处（拖出屏幕了可以去设置里点「恢复默认位置」救回来）；
  - **单击歌词** → 上方浮出工具条：上一首 / 播放暂停 / 下一首 / 小 A / 大 A / 锁定 / 关闭。
    工具条出现时它自己会带一条小底板（这是屏幕上唯一会出现的"框"）；
    再点一次、或**鼠标移开 3 秒**，工具条自动淡出（不是悬停就弹，防止一扫就冒出来）；
  - 工具条那一排按钮和图标的大小可以在设置里调（默认 130%，觉得小可以拉到 180%）；
  - **锁定** = 拖不动它（防误操作），按钮照样能点；
  - **鼠标穿透**（设置里开）= 点歌词会直接穿到下面的软件上，适合边玩边看词。
    注意：穿透时悬浮窗自己收不到点击，所以**关掉它的入口在设置里**，不在悬浮窗上。
- **换歌不会消失**，会自动换成新歌的歌词；一直挂着，直到你再点一次「词」。
- 歌词按 B 站的字幕轨道来：优先真人中文字幕，其次 B 站自动生成的 AI 中文字幕。
- 拿不到字幕时，「词」按钮上方会飘一句提示然后消散（比如「这首没有字幕」）。

**二、整页歌词 —— 点封面打开**

点**播放条最左边那张封面**（或按 `Ctrl + D`），展开整页歌词：

- 当前句高亮放大，整块跟着播放**逐句滚动**；
- **点某一句 → 跳到那一句的时间**，找副歌特别好用；
- 顶部显示歌名和歌手；右上角有「桌面歌词」按钮，不用退回主界面就能开悬浮窗；
- `Esc` 或右上角的 ✕ 收起。

**两个开关是联动的**（都在设置 →「歌词」页）：
**「自动加载歌词」是供词能力，「桌面歌词」是用词方式。**
打开桌面歌词会自动把「自动加载歌词」也打开（不然换歌后悬浮窗没词可显示）；
反过来，手动关掉「自动加载歌词」时，桌面歌词会一起关掉。
同一页里还能调：单行 / 双行、**歌词底板（要不要那块板子）**、字号（14~72）、
**工具条大小（80~180%）**、不透明度（30~100）、锁定位置、鼠标穿透、恢复默认位置。
这些都会记住，下次打开还是你调的样子。

- 播放条上还有个 **↗ 打开视频** 按钮：点一下用**默认浏览器**打开当前这首的 B 站页面。歌词不对时，用它去网页版核对最快。
- 歌词只在本次运行内存着，不写进存档文件（位置和样式除外，它们会记住）。

> 🔧 **为什么之前总是取到别的视频的歌词（已修好）**：B 站把旧的字幕接口 `/x/player/v2` **悄悄降级**了——它不报错，而是随机返回**别的视频**的字幕（连着请求 6 次，只有 1 次是对的；其余是「♪ 音乐 ♪」「今天吃几碗烧烤的总结就是两个字」这类无关内容），而且返回码还是"成功"，从表面完全看不出来。
>
> 现在改走 B 站网页播放器真正在用的那条接口（`/x/player/wbi/v2`，带 WBI 签名），实测 6/6 全部正确。另外还有三重兜底：核对 `cid` 属于哪个视频、识别诱饵内容、失败自动重试 3 次；歌词来源和当前歌曲对不上时，歌词顶部会显示橙色提示条告诉你。
>
> 真的遇到取不到时，多数是**没填 Cookie** 或**这个视频确实没有字幕**，界面上会分别告诉你原因。也可以点 **↗ 打开视频** 去 B 站网页版直接看字幕。

> 💡 进度条现在可以**按住拖动**跳转了；音量也会记住上次的大小。
>
> 另外，窗口已经是**无边框**的——原来顶上那条跟系统配色跑、在深色下格外扎眼的白边没有了，取而代之的是一条跟着主题走的自绘标题栏（半透明磨砂质感）；右上角的最小化/最大化/关闭三个按钮也改成了我们自己画的 HTML 按钮，和标题栏无缝一体、一起跟随主题色（悬停会染上主题色，关闭按钮沿用"变红"习惯）；播放条和侧边栏的所有按钮也都换成了统一的单色 SVG 图标，深色界面下不再花花绿绿、对不齐。

## 三、重要：遇到"搜索失败 / 被限流"怎么办

B 站对未登录的请求有**随机限流**。如果你发现搜索时好时坏，用这个办法解决：

1. 浏览器打开 <https://www.bilibili.com> 并登录
2. 按 `F12` → 点顶部「Application」（中文版叫「应用程序」）
3. 左侧找 `Cookies` → `https://www.bilibili.com`
4. 找到名字是 **`SESSDATA`** 的那一行，复制它的值
5. 回到播放器，点左下角 **⚙ 设置**，切到「B 站」标签页，把 SESSDATA 粘进去

填完之后搜索会稳定非常多。**不填也能用，只是偶尔需要多点两次。**

> 🔒 Cookie 只保存在你自己电脑的 `%APPDATA%\neko-music\cookie.txt`，不会上传到任何地方。

## 四、代码是怎么工作的（零基础讲解）

### 为什么不用普通网页，而要用 Electron？

浏览器里打开一个网页，**没法**自由地访问别的网站（叫"跨域限制"），也存不了本地文件。
Electron 相当于把"浏览器"和"Node.js"焊在一起，让我们的界面既有漂亮的样子，又有程序的权限。

### 文件都是干什么的

```
Music/
├── package.json          ← 项目说明书（叫什么名、要装哪些库）
├── 启动播放器.vbs         ← 双击启动（没有黑窗口）
├── 调试启动.bat           ← 出问题时双击它看日志
└── src/
    ├── main.js           ← 主进程（幕后老板，还负责开第二个歌词窗口）
    ├── preload.js        ← 传话筒（安全的沟通桥梁）
    ├── preload-lyric.js  ← 悬浮歌词窗专用的传话筒（权限更小）
    ├── bilibili.js       ← 和 B 站对话的翻译官
    └── ui/
        ├── index.html    ← 骨架（页面上有哪些元素）
        ├── style.css     ← 化妆（长什么样）
        ├── app.js        ← 大脑（点了什么，做什么）
        ├── lyric.html    ← 桌面歌词窗的骨架（第二个窗口）
        ├── lyric.css     ← 桌面歌词的样式
        └── lyric.js      ← 桌面歌词的逻辑（算当前句、拖动、工具条）
```

**为什么分 main 和 ui 两个进程？**

- `ui/` 里的代码跑在"网页世界"，很安全但没权限
- `main.js` 跑在"系统世界"，有权限但没法画界面
- 两个世界通过 `preload.js` 喊话：界面说"帮我搜一下钢琴"，主进程搜完把结果递回来

### 三个最关键的技术点

#### 1️⃣ wbi 签名（`bilibili.js`）

B 站为了防止别人乱调接口，要求每个搜索请求带一个**签名**。算法是：
把参数按字母排序 → 拼成字符串 → 用一张固定的乱序表从"钥匙"里抽字符 → MD5。

这套算法藏在 `getWbiKeys()` 和 `signParams()` 里。你不需要理解它，只要知道**它是搜索能成功的前提**。

> ⚠️ 有个坑我在开发时踩过：取"钥匙"的那个接口（`nav`）在未登录时会返回 `code: -101`，
> 但数据里照样有钥匙。所以那一步不能走"必须 code=0"的通用函数，得手动解析。

#### 2️⃣ bili:// 协议（`main.js`）—— 最巧妙的一步

B 站的音频地址有**防盗链**：必须带着 `Referer: https://www.bilibili.com` 才让下载。
可网页里的 `<audio>` 标签**没法自定义请求头**，这不是死路了吗？

解法是自己造一个协议：

```
网页写：  <audio src="bili://get?url=真实音频地址">
Electron 收到 → 由主进程代发请求，帮它加上 Referer → 把音频数据流回去
```

界面完全感觉不到中间这层，就像播放本地文件一样自然。
代码在 `registerBiliProtocol()` 里，一共 20 行。

#### 3️⃣ 不要下载视频，只要音频

B 站把视频和声音**分开存放**（叫 DASH 格式）。
调 `playurl` 接口时传 `fnval=16`，就会返回一个 `dash.audio` 数组 —— 里面是**纯音频**的地址。

这样一首歌只要几 MB，还能秒开。如果下载整个视频，光是流量就浪费十倍。

#### 4️⃣ 内容安全策略（CSP）与"封面破图"

页面 `<head>` 里有一行 `Content-Security-Policy`，它规定了网页**只允许从哪里加载资源**。
我们写的是 `img-src 'self' https: data:` —— 图片只准用 https。

而 B 站的搜索接口很"随意"，封面地址经常返回 `http://i1.hdslb.com/...`（少个 s）。
结果就是：所有封面被浏览器拦下，变成破图，控制台里刷满
`Refused to load the image ... violates the following Content Security Policy directive`。

**修法**是在 `bilibili.js` 里加一个 `toHttps()`，把所有图片地址统一成 https 再交给界面。
这个小函数解决了三种写法：`http://xxx`、`https://xxx`、`//xxx`（省略协议的）。

> 📌 顺便说一句：我们**没有**去放宽 CSP 让它接受 http，因为那样只是把问题藏起来；
> 正确的做法是把数据整理干净。当然，双保险也加了（CSP 里额外放行了 B 站的图片域名）。

#### 5️⃣ bg:// 协议与自定义背景（`main.js`）

背景壁纸也走自己造的协议。页面安全策略里**没有**放行 `file://`，
与其把 CSP 开个大口子，不如造一个只能读取 `backgrounds/` 这一个目录的 `bg://` 协议：

- 选图时弹系统文件框，把图片**复制**进 `%APPDATA%\neko-music\backgrounds\`，换掉原图也不会裂
- 协议有两道安全闸：文件名白名单（挡 `..`、反斜杠这类路径穿越写法）+ 路径越界检查（挡符号链接逃逸）
- 为将来的「视频背景」预留了流式传输能力

外观（主题色、背景、毛玻璃）全部由 CSS 变量驱动：切换主题**只改点缀色、绝不碰底色**，
所以你的自定义背景和主题色永远不会打架。

## 五、打包成一个独立的 .exe

想发给朋友、或者当成正常软件用（不用开终端）：

```powershell
npm run build
```

完成后在 `dist/` 文件夹里会出现一个安装包。双击安装，以后从开始菜单就能打开。

> 第一次打包会下载额外工具，比较慢。如果卡在下载，说明网络不通，可以跳过这步 —— 用 `启动播放器.vbs` 已经足够日常使用了。

## 六、常见问题

**Q：播放没声音？**
先检查右下角系统音量，再把鼠标移到播放器右下角的**喇叭图标**上，把浮出来的竖条拉到中间以上（点一下喇叭图标是静音开关，别是静音状态）。如果还是不行，双击 **`调试启动.bat`** 启动它，窗口里会显示出错原因（复制那几行红色文字发给作者就行）。

**Q：提示"音频加载失败了，可能链接已过期"？**
B 站的音频地址有时效（几小时）。重新点一下这首歌就好。

**Q：搜索成功但点播放没反应？**
某些视频是会员专属或有版权限制，拿不到音频流。换一首试试。

**Q：双击 `启动播放器.vbs` 没有任何反应？**
按这个顺序排查：

1. 先试 **双击 `调试启动.bat`** —— 它会把错误直接打出来，截图发我最快
2. 确认 `node_modules\electron\dist\electron.exe` 这个文件存在（应该有 188 MB 左右）
3. 打开终端（地址栏输入 `cmd` 回车），运行 `node_modules\electron\dist\electron.exe .`，把红色报错发出来

> 万一双击 `.vbs` 被系统或杀毒软件拦了，就用 `调试启动.bat` 代替，功能完全一样，
> 只是会多一个黑窗口（那个窗口是故意的，关掉软件它自己会消失）。

**Q：明明没开别的程序，却多了一个黑窗口不停刷字？**
那是 **`.bat` 启动方式**的特征 —— electron 会继承 bat 的控制台，bat 退出后
窗口被它拽着不放。改用 `启动播放器.vbs` 就没有了（原理见上方第一节）。

**Q：封面是空白的？**
已经修好了。原因是 B 站返回的封面地址是 http，被页面的安全策略拦下（详见第四节第 4 点）。
如果你看到的是老版本，重启一下软件即可。

**Q：选了背景图却不显示 / 显示裂图？**
背景图走 `bg://` 私有协议读取，存在 `%APPDATA%\neko-music\backgrounds\`。
排查：① 确认图片是 png / jpg / webp / gif / bmp；② 双击 `调试启动.bat` 看有没有红色报错；
③ 点「清除背景」再重新选一次。

**Q：软件打不开 / 白屏？**
双击 `调试启动.bat`，看黑窗口里打印的报错信息 —— 那里会有明确的原因。

**Q：改代码改坏了，歌单收藏会不会丢？**
不会，你的数据在**另一个地方**，跟代码完全分开：

```
C:\Users\你的用户名\AppData\Roaming\neko-music\neko-data.json
```

怎么手动备份：按 `Win + R`，输入 `%APPDATA%\neko-music` 回车，
把 `neko-data.json` 复制一份到桌面就行。

万一真丢了数据，把备份文件改回 `neko-data.json` 放回原目录，重启软件即可恢复。

> 每次大改之前，我都会先帮你把这个文件备份一份到桌面，名字带时间戳，比如
> `neko-data.备份.20261007-040136.json`。看到这种文件就是备份，别删。
